# Flow downloads

**[Download Flow →](https://platiniumtermite.github.io/flow-downloads/)**

Flow shares files, folders, text, links, clipboard and screens wirelessly between your computers — like AirDrop, for Mac and Windows.

This repository hosts the download page and release binaries. Each release includes:

- `Flow-*-Mac-arm64.dmg` — Apple silicon Mac disk image
- `Flow-*-Windows-x64-Setup.exe` — Windows x64 installer
- `START-HERE.md` — full install and pairing guide
- `SHA256SUMS.txt` — integrity checksums

Unsigned alpha builds: your OS may warn on first launch. See START-HERE.md in the latest release.
