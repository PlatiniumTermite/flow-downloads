Everything moves with you.

One install on each computer and they behave like one device — no cables, no uploads, no accounts.

Any file, any size

Documents, media, archives, code — one transport, integrity-verified, up to your disk quota.

Whole projects

Drop an entire folder — up to 500 files queued, relative paths preserved, one Accept-all.

Shared clipboard

Copy on the Mac, paste on the PC. Opt-in text clipboard sync while the space is open.

Self-healing connections

Wi-Fi drops mid-transfer? Flow reconnects itself and re-offers interrupted files.

Nearby by name

Your computers discover each other on the same Wi-Fi — tap Connect, tap Allow, done.

Private by design

Secrets are never broadcast — the host approves each pairing. Data travels device-to-device.

Three steps. That’s it.

1

Install on both computers

A normal installer on Windows, drag-to-Applications on Mac. No Node.js, no terminal.

2

They find each other

Same Wi-Fi, then enable Find nearby Flow computers once on each machine.

3

Tap, allow, done

Press Connect on one side, Allow on the other. Everything flows from there.

Alpha builds — a heads-up before you install. These are unsigned test builds, not a trusted-publisher release. Your OS may warn the first time; this is expected for unsigned alpha software.
What to expect
  • Windows: SmartScreen may show “Windows protected your PC”. Choose More info → Run anyway.
  • Mac: if Gatekeeper blocks the first launch, right-click Flow in Applications → Open → Open again. Apple silicon Macs only.
  • Keep both computers on the same trusted Wi-Fi; allow Flow on your private network if the firewall asks.
